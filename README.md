# Pemrosesan Teks (NLP)

Kumpulan tugas dan eksperimen untuk mata kuliah **Pemrosesan Teks / Natural Language Processing (NLP)**.

## 📂 Struktur Tugas
* `notebooks/`: File Jupyter Notebook (`.ipynb`) tiap tugas.
* `data/`: Dataset mentah dan hasil olahan.

## 🛠️ Modul Utama
Python 3 | Pandas | NLTK | Sastrawi | Scikit-Learn

## 🚀 Cara Menggunakan
1. Buka folder `notebooks/`.
2. Buka file `.ipynb` di Google Colab.
3. Install library yang dibutuhkan: `!pip install sastrawi nltk`
